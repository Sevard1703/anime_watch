# AnimeWatch

AnimeWatch — это современный многостраничный сайт для просмотра аниме, созданный на чистом HTML, CSS и JavaScript без использования фреймворков и библиотек.

## О проекте

Проект представляет собой полноценный интерфейс аниме-платформы с тёмной эстетикой, адаптивным дизайном и удобной навигацией. В нём реализованы:

- главная страница с баннер-слайдером, секциями аниме и блоком продолжения просмотра;
- каталог тайтлов с фильтрами, поиском, сортировкой и пагинацией;
- страница жанров с переходом к отфильтрованному каталогу;
- страница отдельного аниме с описанием, сериями, вкладками и возможностью добавления в избранное;
- страница просмотра с видеоплеером, списком серий и рекомендациями;
- страница поиска и личный кабинет с избранным, историей просмотра и настройками.

## Технологии

- HTML5
- CSS3
- JavaScript (vanilla)
- LocalStorage для сохранения избранного

## Особенности

- современный тёмный UI в стиле популярных аниме-платформ;
- полностью адаптивный дизайн для мобильных, планшетов и десктопов;
- плавные анимации и интерактивные элементы;
- чистая структура кода и комментарии в JavaScript.

## Запуск

Откройте любой из файлов в браузере напрямую, например:

- `index.html` — главная страница
- `catalog.html` — каталог
- `categories.html` — жанры
- `anime.html` — страница аниме
- `watch.html` — страница просмотра
- `search.html` — результаты поиска
- `profile.html` — личный кабинет

## Цель проекта

Создать красивый, удобный и функциональный прототип аниме-сайта, который можно дальше развивать как полноценный веб-проект.
